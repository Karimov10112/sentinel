PSI (Population Stability Index) — kiruvchi oqimlardagi asosiy belgilar taqsimotining o‘quv to‘plamidan farqi: < 0,1 — barqaror, 0,1–0,25 — kuzatish, > 0,25 — jiddiy siljish (chegarani qayta kalibrlash yoki modelni qayta o‘qitish tavsiya etiladi).

Oylik qayta o‘qitish tartibi

  1. Pilot davrida (2–4 hafta) tizim passiv ishlaydi, mahalliy normal trafik yig‘iladi, chegara kalibrlanadi.
  2. Tahlilchilar insidentlarni «Haqiqiy hujum» / «Soxta ogohlantirish» deb baholaydi.
  3. Oy oxirida yorliqlar eksport qilinadi: tahlilchi_yorliqlari.csv.
  4. Model mahalliy ma’lumotlar bilan qayta o‘qitiladi: python train/adapt.py --local local_normal.csv --labels tahlilchi_yorliqlari.csv.
  5. Yangi model avval passiv rejimda solishtiriladi (Precision, FPR, soxta ogohlantirishlar soni), so‘ng faollashtiriladi.

SI modulining o‘z xavfsizligi (2.8-band)

  • Chetlab o‘tish (evasion): SI moduli signatura vositalari (Suricata) bilan birga ishlaydi; autoenkoder XGBoost o‘tkazib yuborgan anomaliyalarni P4 sifatida qayd etadi.
  • Zaharlash (poisoning): qayta o‘qitishga faqat tahlilchi tasdiqlagan yorliqlar va tekshirilgan normal trafik kiradi.
  • Model o‘g‘irlash: API kalit bilan himoyalangan, ichki tarmoqda ishlaydi.
  • Siljish: PSI va ogohlantirishlar hajmi har tahlilda kuzatiladi.
